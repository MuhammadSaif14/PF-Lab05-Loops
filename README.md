# PF Lab 05 – Loop Tasks

This repository contains my solutions for **Lab#05** of the course **CL-1002 Programming Fundamentals** (FAST-NUCES, Fall 2026), taught by Sir Muhammad Aais Rabbani.

All programs are written in **C**, using `printf` and `scanf` for input and output, and the specific loop named in each question (`for`, `while`, or `do-while`).

## Programs Included
1. **Scoring an Over in Cricket** (`for` loop) – takes runs for 6 balls and shows total runs, boundaries, and dot balls.
2. **Saving for a Laptop** (`while` loop) – shows monthly savings until Sara can afford the laptop, and the number of months needed.
3. **ATM PIN Verification** (`do-while` loop) – allows 3 attempts to enter the correct PIN, then grants access or blocks the card.
4. **Class Result Summary** (`for` loop) – shows passed and failed students, highest marks, and class average using explicit typecasting.
5. **University Canteen Order** (`do-while` loop) – menu-based ordering program with running bill, 10% discount above Rs 1000, and final payable amount.

## How to Run
```bash
gcc filename.c -o output
./output
```
